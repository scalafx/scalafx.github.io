## Further Resources

Where to go next: example code, API docs, books and places to ask questions.

### Example projects

| Project                                                                               | What it is                                                                                                 |
|---------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------|
| [ScalaFX Ensemble](https://github.com/scalafx/scalafx-ensemble)                       | A gallery of ScalaFX controls and features, with the source for each.                                      |
| [ScalaFX Tutorials](https://github.com/scalafx/ScalaFX-Tutorials)                     | Small standalone projects: tables, cell factories, dialogs, 3D, FXML and more.                             |
| [scalafx-hello-world](https://github.com/scalafx/scalafx-hello-world)                 | The smallest SBT project that runs.                                                                        |
| [ScalaFX-Hello-World-Gradle](https://github.com/scalafx/ScalaFX-Hello-World-Gradle)   | The same, built with Gradle.                                                                               |
| [scalafx.g8](https://github.com/scalafx/scalafx.g8)                                   | The Giter8 template used in "For the Impatient".                                                           |
| [ProScalaFX](https://github.com/scalafx/ProScalaFX)                                   | Examples from the *Pro JavaFX* books, translated to ScalaFX. Older code, so treat it as a source of ideas. |

### Libraries

- [ScalaFX Extras](https://github.com/scalafx/scalafx-extras) — helpers that have no JavaFX equivalent: custom dialogs, progress indicators for batch jobs, image views with zoom, and an MVC pattern for FXML apps.

### Reference

- [ScalaFX API (Scaladoc)](https://javadoc.io/doc/org.scalafx/scalafx_3)
- [ScalaFX release notes](https://github.com/scalafx/scalafx/releases)
- [JavaFX documentation](https://openjfx.io/) — [getting started](https://openjfx.io/openjfx-docs/) and [API docs](https://openjfx.io/javadoc/26/). ScalaFX wraps JavaFX, so these apply directly.

### Books and videos

- Mark C. Lewis and Lisa L. Lacher, [*Introduction to Programming and Problem-Solving Using Scala*](https://digitalcommons.trinity.edu/mono/59/) (CRC Press, 2nd ed.). It teaches Scala from scratch and includes chapters on GUIs and ScalaFX.
- [Mark Lewis on YouTube](https://www.youtube.com/@MarkLewis/) — video lectures that go with the book, some using ScalaFX.

### Blogs and talks

- [Coding on the Staircase](https://codingonthestaircase.wordpress.com/category/scalafx/) — Jarek Sacha's practical ScalaFX recipes.
- Stephen Chin, ["JavaFX 2 and Scala: Like Milk and Cookies"](https://www.slideshare.net/steveonjava/javafx-2-and-scala-like-milk-and-cookies-33rd-degrees) (2012) — background on the design, not on current syntax.
